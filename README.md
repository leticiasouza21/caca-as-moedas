
# 🪙 CAÇA ÀS MOEDAS

### 🎮 30 segundos. Um desafio. Quantas moedas você consegue coletar?

Bem-vindo ao **Caça às Moedas**, um jogo interativo que combina velocidade, atenção e diversão!

Prepare seus reflexos, fique de olho no cronômetro e tente conquistar a maior pontuação possível antes que o tempo acabe.

## 🎯 Sobre o Jogo

O Caça às Moedas é um jogo desenvolvido em Python, com interface gráfica intuitiva e partidas rápidas de 30 segundos.

Durante a partida, moedas aparecem em posições aleatórias na tela. Sua missão é coletar o máximo possível, acumular pontos e superar seu próprio recorde.

## 🕹️ Como Jogar

1. Clique em **Iniciar Jogo**.
2. Observe as moedas que aparecem na tela.
3. Clique nas moedas para coletá-las.
4. Acumule o máximo de pontos em 30 segundos.
5. Supere seu recorde a cada nova partida!

## 💰 Sistema de Pontuação

🟡 **Moeda Dourada:** +1 ponto

🔴 **Moeda Especial:** +5 pontos

🏆 **Recorde:** acompanhe sua maior pontuação durante a sessão.

## ✨ Funcionalidades

- 🎮 Interface gráfica interativa.
- ⏱️ Cronômetro com contagem regressiva.
- 🪙 Geração automática de moedas.
- 💎 Moedas especiais com pontuação extra.
- 🏆 Sistema de recorde.
- 🔄 Opção de jogar novamente.
- ⚡ Execução concorrente de tarefas.
- 🔒 Sincronização de dados compartilhados.

## 🛠️ Tecnologias Utilizadas

- **Python:** desenvolvimento do jogo.
- **Tkinter:** construção da interface gráfica.
- **Threading:** execução concorrente e sincronização.
- **Random:** geração aleatória das moedas.
- **Time:** controle dos intervalos de execução.

## 🚀 Como Executar

### Requisitos

- Python 3 instalado.
- Tkinter disponível no ambiente.

### Passo a passo

1. Baixe o projeto.
2. Abra a pasta do jogo.
3. Execute o comando:

```bash
python jogo.py
```

4. Divirta-se!
